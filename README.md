# Qxfer

یک صفحه، دو دکمه، بدون CDN. سرور Flask فایل‌های محلی را می‌دهد و نشست فرستنده/گیرنده را روی API نگه می‌دارد.

کد تصویری **Beacon Grid** است نه QR: خانه‌های درشت سیاه/سفید، حاشیه سبز برای قفل دوربین، و چهار هدف گوشه.

```bash
pip install -r requirements.txt
python -m qrxfer
```

روی لپ‌تاپ `http://127.0.0.1:8080/` باز می‌شود. **گوشی `127.0.0.1` لپ‌تاپ نیست**؛ آدرس USB/LAN که در ترمینال و بالای صفحه چاپ می‌شود را بزنید، مثلاً `http://192.168.137.1:8080/`.

اگر گوشی با کابل و USB debugging وصل است، `adb reverse` خودش زده می‌شود و روی گوشی هم `http://127.0.0.1:8080/` کار می‌کند (برای دوربین بهتر است).

گیرنده کد نشست را وارد می‌کند و با «شروع کن» اجازه ارسال می‌دهد.

اگر صفحهٔ قبلی کش شده، یک‌بار hard-refresh کنید (Ctrl+F5).
