# Qxfer

یک صفحه، دو دکمه، بدون CDN. سرور Flask فایل‌های محلی را می‌دهد.

کد تصویری **Beacon Grid** است نه QR: خانه‌های درشت سیاه/سفید، حاشیه سبز برای قفل دوربین، و چهار هدف گوشه.

```bash
pip install -r requirements.txt
python -m qrxfer
```

اگر صفحهٔ قبلی کش شده، یک‌بار hard-refresh کنید (Ctrl+F5).

`python app.py` هم همان UI را روی پورت 8080 بالا می‌آورد.
